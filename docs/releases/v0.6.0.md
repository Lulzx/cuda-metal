# CuMetal v0.6.0

[Release index](README.md)

CuMetal 0.6.0 is mostly about the typed PTX backend, which the project is
converging on. An external contributor's 76-commit import stack (PRs #49-#167)
landed. It lets Rust-CUDA cryptographic kernels translate, and it brought eight
silent regressions that the corpus gate caught and this release fixes. Two
more external workloads now run: AMReX, and PhysX's position-based dynamics.
Generated Metal source is much smaller for bit-heavy kernels, because Apple's
compile time tracks emitted operation count.

## Highlights

- **AMReX's CUDA backend runs on the Apple GPU with no AMReX patches.** The
  HeatEquation tutorial agrees with a CPU build to 5.5e-09 relative after 200
  steps. Two of the fixes behind it are general. `std::`-qualified math now
  works in device code. Device code now compiles with `-fno-strict-aliasing`,
  as nvcc does, because Clang's TBAA was deleting AMReX's punned warp
  reductions and every GPU min/max returned zero.
- **Silent wrong answers fixed.**
  - On the driver path, promoted `__device__` globals had no storage: a counter
    initialized to 5 and bumped by 7 read back 7 on every launch.
  - Kernels with arguments at buffer indices 26-29 had them overwritten by
    hidden bindings.
  - The direct PTX->MSL emitter compiled `x / 3` and float warp shuffles
    wrong. It now declines anything it cannot type instead of guessing.
  - On the legacy LLVM path, a non-immediate `lop3` table became `0xf0`.
  - The import-stack merge made `txq`/`suq` dimension queries read zero.
- **Smaller generated source for bit-heavy kernels** (#115, #124, #133).
  - Sign-free immediate `prmt.b32` is a single byte swizzle.
  - Constant-count `shf.wrap` and constant `bfi` fold to a few shifts and
    masks.
  - 64-bit `mul.hi`, `clz` and `popc` use Metal's 64-bit builtins.

  Measured with `xcrun metal -c` on 3,000-instruction kernels, compile time
  fell 2-4.5x for each form, for example 1.18 s to 0.26 s for `mul.hi.u64`.
- **Typed-backend coverage.** The PTX importer now handles `brev` and `lop3`,
  checked against a GPU oracle for all 256 truth tables. It also covers the
  reachable libdevice math surface, including exact directed-rounding interval
  intrinsics.
- **Diagnosability.**
  - `cuFuncLoad` and `cuFuncIsLoaded` separate compile failures from launch
    failures.
  - Stage tracing now spans PTX import through Metal pipeline creation.
  - Registration forwards the compiler's refusal reason instead of reporting
    a missing metallib.
- **Toolchain.** The AIR version is probed from the installed Metal
  toolchain, so Xcode 27's AIR 2.9 linker works. A pinned Nix development
  shell is available. `ctest -LE slow` is a three-minute inner loop when the
  build is warm.

## Verification

On the recorded Apple M4 Pro system, macOS 27, Debug with the binary shim enabled:

- The full suite passed **392/392**, run serially (1,786 s), at `bb5c8ba`. That
  includes the typed-PTX and native-AOT corpora, the compiler backend matrix
  across CUDA Clang 21-23, the cuda-samples sweep, PhysX GRB and PBD
  conformance, llama.cpp and the PTX sweeps.
- After the version bump, `unit_version_matches`, `unit_cumetal_cli` and
  `unit_documentation_consistency` passed again.

The binary-shim-OFF and Release configurations were **not** rerun for this
release.

These totals are evidence for the enrolled test surfaces, not a percentage of
the complete CUDA ecosystem.

## Important limits

- Issues #115, #119, #124 and #133 are still open. The source-size reductions
  target the constructs those workloads were measured to contain. No new
  downstream RSA or Ethereum GPU run has been made, so none of those issues is
  claimed fixed.
- #76 remains open for the Bitcoin and Ethereum LLVM7 self-tests.
- Extended-precision carry chains (`add.cc`/`addc`, `sub.cc`/`subc`,
  `mad.cc`/`madc`) are unsupported on every PTX backend and refuse the kernel.
- The PhysX PBD scenes carry the four limits recorded in their README,
  including spring constraints that have no effect. Particle systems of 1024
  or more stop integrating.
- Apple Silicon/macOS only. There is no SASS execution, multi-GPU transport,
  NVIDIA management telemetry or graphics interop. Library shims are tested
  subsets, and NVIDIA bitstream or numerical parity is not claimed.
